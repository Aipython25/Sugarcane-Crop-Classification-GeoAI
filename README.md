# Sugarcane Crop Classification using GeoAI 🌾🛰️

This project focuses on sugarcane crop classification using Satellite Imagery, GIS, and Machine Learning techniques. The goal of this project is to identify and monitor sugarcane crop areas for precision agriculture and decision-making.

---

## 🎯 Project Objective

To develop an accurate and scalable sugarcane crop identification & monitoring system using Remote Sensing, GIS, and Machine Learning.

---

## 🛠️ Technology Stack

- Satellite Data: High-resolution satellite imagery  
- GIS Platform: ArcGIS 10.8  
- Programming: Python  
- Machine Learning Algorithm: Random Forest Classifier  
- Ground Truth Data: Field reference & visual interpretation  

---

## 📊 Land Use & Crop Classes

- 🟫 Bare Land – Uncultivated agricultural land  
- 🟩 Cane Crop – Active sugarcane cultivation  
- 🟦 Other Land – Built-up, vegetation, and non-agricultural land  

---

## 🔍 Methodology

1. Satellite data preprocessing  
2. Training sample collection  
3. Feature extraction  
4. Random Forest model training  
5. Pixel-based classification  
6. Accuracy assessment  
7. Final crop classification output  

---

## ✅ Results

- Sugarcane crop detected with ~90% accuracy  
- Clear separation of agricultural and non-agricultural land  
- Useful for real-world agriculture planning  

---

## 🌱 Real-World Applications

- Precision Farming  
- Crop Insurance  
- Yield Estimation  
- Irrigation Planning  
- Government Agriculture Projects
